# 🌾 Kisan Sahayak AI - Farmer's Production AI Advisor

Production-Grade Multilingual AI Platform providing real-time Crop Disease Diagnosis (Vision Transformer), Urdu Voice AI, Smart Irrigation, and Market Price Forecasting.

## 🛠️ Tech Stack
- **Backend:** FastAPI (Python 3.11+) + LangGraph Multi-Agent Workflows + Qdrant Vector Store
- **Frontend:** Next.js 15 + TypeScript + TailwindCSS
- **Database:** PostgreSQL + Redis + Qdrant
